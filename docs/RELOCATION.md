# 移动 Bark.app

2.6.2 开发候选移除固定安装路径依赖。首次安装默认放在系统“应用程序”，之后可把实际 App 移至同一磁盘的其他可读写文件夹，也可以更改文件夹或 App 名称。手机地址、来源规则与历史仍由同一 macOS 用户的 Application Support 目录保存。

程序通过 macOS 普通文件书签记住当前应用，登录启动调用固定数据目录中的短命启动入口，无新增后台轮询或常驻服务。关闭程序后移动，再次登录时也由书签解析位置。程序运行中被移动时，设置和更新从当前进程实际文件位置获取路径。书签目标不可用时停止启动，不会随便找一个同名 App。

程序更新将当前实际 App 作为事务目标，更新成功或回退后重建书签，避免旧文件的书签随着交换移动到备份。更新只更换程序，保留原有设备、规则和偏好。

第一次升级到此版本需先打开一次，让程序登记书签。跨磁盘复制后删除原件、卷未挂载、文件权限不足或删除 App 不保证能自动定位；手动打开目标 App 后会重新登记。移动不改变代码签名，仍需遵守 macOS 安全打开流程。尚未作为新公开 Release 发布，实际验证结果见本轮候选验收记录。
