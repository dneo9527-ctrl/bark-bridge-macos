# Agy Console 提醒

Bark 2.6.2-preview.2（Build 51）加入 Agy Console 来源。兼容的控制台在保存任务最终结果后，将少量事件元数据交给本机 Bark；控制台需包含终态事件适配，本机对应 Agy Console 0.1.0-preview.13。

- 推送本轮完成和最终失败，包含会话名称及结果类别；手机内容预览关闭时隐藏名称。
- 额度自动候补只通知最终结果；取消、重启时发现的历史未完成任务不推送，旧记录不回放。
- 不发送提示词、模型回复、原始错误、命令或账号信息。Bark 本机历史保留脱敏发送结果，手机 Bark 保存提醒。
- 与现有手机、指定设备路由、总开关、来源开关、临时静音和每日勿扰共用规则。来源删除后忽略事件，重新使用模板不会开启原本停用的来源。

在 Bark 的“来源”中管理 Agy Console；也可在“内置接入模板”添加。无新增守护进程或文件轮询。事件接入调用短命进程并给入口一秒超时，网络发送由原有异步工作进程处理；发送失败不改变 Agy 任务结果。

此适配仅覆盖兼容的本机 Agy Console；独立 Agy CLI、Antigravity IDE 未接入。当前控制台没有可靠的等待授权／回答事件，不从回复中的问号猜测等待状态。

## 配套分发与验证

本机开发部署的控制台版本为 `0.1.0-preview.13`，不代表同号完整安装包已经公开。公开 Agy `.8` 不含本次生产者，仅安装或升级 Bark 不会为旧控制台补入事件。配套控制台需在自己的完整发行中合入兼容生产者并验收；本仓库不夹带整份控制台或修改你的 Agy 安装。

Bark 的接收端、来源路由、暂停和隐私规则已做隔离测试；控制台生产者提供 11 项合成测试及本地完整回归。一次明确标记为接入测试的事件获网关 HTTP 200，手机实收和真实新模型任务触发仍未确认。网关接受不等于手机送达。
