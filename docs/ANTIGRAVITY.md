# Antigravity App 通知

2.6.2-preview.3（Build 52）接入 Google 原生 Antigravity.app（bundle ID `com.google.antigravity`）的官方生命周期 Hook。此前 Build 51 的 Agy Console 适配属于不同软件，不能代替原生 App。

**实验性接入，尚未完成真实事件验收。** 原生 2.32.2 的专用测试遇到模型服务不可用，已取消测试且未更换模型或权限。真实 `ask_question`／正常结束、空 JSON 在原生执行链中的动态中立性和手机实收尚未确认。24 项新增隔离测试及合成网关 HTTP 200 不能替代这些验收。本机来源列表图标已确认；手机图标的改进见下文，实际展示仍需单独确认。

在 Bark“内置模板”选择 **Antigravity App**。程序查找实际 App 位置，合并全局 `~/.gemini/config/hooks.json` 中专属命名组；修改前保存受限备份，保留第三方 Hook、授权策略和已停用状态。来源可选择设备、临时静音及每日勿扰，共用当前手机配置。来源显示原生 App 图标；其他未知来源不会套用 Codex 图标。

2.6.2-preview.9（Build 58）补齐 iPhone 推送中的 Antigravity 彩色图标，提问、资源授权、完成和来源测试共用同一个官方图源。原生 Antigravity 通知保存在手机 Bark 历史（`isArchive=1`）；Mac 记录继续脱敏。图标由手机联网加载，网关接受不等于手机已显示，旧通知不补图。参见[第三方图稿说明](THIRD_PARTY_ARTWORK.md)。

当前支持：

- `ask_question` 工具提问：提醒问题与简短选项。
- `ask_permission` 工具申请新增资源权限：提醒返回 App 决定。它不代表所有操作审批；普通命令等默认审批没有独立可用 Hook，不能保证捕获。
- `Stop` 正常结束：只接受明确正常、完全空闲且未处于 Hook 强制继续的事件。取消、错误、额度／步数上限、终止型工具和仍有后台任务的停止不冒称完成。

官方全局配置同时供其他 Antigravity 界面使用。接收端仅依据输入中的本机路径字符串确认原生 App，忽略 CLI、IDE 和子代理事件；不打开路径对应的聊天记录。仅问题预览、项目简称及会话短编号用于手机提醒，不发送完整提示词、回复、命令、权限目标或错误正文。关闭“手机内容预览”会隐藏问题、项目和会话编号。

Hook 返回空 JSON，不返回授权、拒绝、权限覆盖或继续执行决定。发送网络请求由原有短命工作进程承担，失败不会阻塞工作。配置完成不等于手机已实收；新会话应重新载入 Hook。

普通文字提问未调用 `ask_question` 时无法保证提醒。远程执行、旧版或改变协议的 App、睡眠离线以及推送链路故障也不保证捕获。真实覆盖应以当前版本的现场测试为准。

参见 [Google 官方 Hook 文档](https://antigravity.google/docs/hooks)。
