从 Mac，连接到你的手机。

Bark Bridge 2.6.0 · Apple Silicon 开发者预览

尚未使用 Developer ID 签名或 Apple 公证。
首次打开可能被 macOS 拦截。请核对来自本项目的下载与 SHA-256 校验值，再阅读 Apple 安全打开说明，由你决定是否信任并打开。

首次安装

  1. 在 Apple Silicon Mac 上解压 ZIP，打开 Install Bark Bridge.app。内置 Python，无需 Xcode、终端或 pip。
  2. 查看安装位置；已找到 Codex CLI 时，可以勾选接入默认 ~/.codex。点击「安装并打开」。
  3. 在 iPhone 安装 Bark 并允许通知；将 Bark 首页的 HTTPS 地址填入 Mac 面板的「接收设备」隐藏输入框。
  4. 发送测试，在手机上确认收到。手机显示提醒；回答和审批仍回到 Mac。

支持目标 macOS 13+；本预览只在 macOS 26、Apple Silicon 实机验证，不含 Intel 版本。

已有安装

安装助手只支持首次安装。检测到 /Applications/Bark.app 或 ~/Library/Application Support/CodexBark 已存在会停止，不覆盖设备配置、规则或备份。本预览没有自动升级器。

接入其他 Codex 目录

没有找到 CLI，或使用多个独立 CODEX_HOME 时，先安装 App，再按 完整接入指南操作。已有接入目录换账号无需重新填写手机地址。

安装失败与卸载

如果安装中途停止，共用运行目录和配置备份会保留。请先核对安装指南中的恢复步骤，不要反复运行安装，也不要删除正在使用的目录。在 App「设置 → 高级 → 卸载」移除通知入口；保留备份目录供检查。
