首次安装

  1. 在 Apple Silicon Mac 上完整解压首次安装 ZIP，双击 Install Bark Bridge.app。内置 Python 3.13.18，无需 Xcode、终端或自行装 Python。
  2. 查看安装位置 /Applications/Bark.app；已找到 Codex CLI 时，可以勾选接入默认 ~/.codex。点击「安装并打开」。
  3. 在 iPhone 安装 Bark 并允许通知；将 Bark 首页的 HTTPS 地址只填入 Mac 面板的「接收设备」隐藏输入框，不发到聊天、Issue 或截图。
  4. 发送测试，在手机上确认收到。手机显示提醒；回答和审批仍回到 Mac。手机联网、APNs 与推送服务会影响 Wi-Fi/移动网络送达，离线不保证实时收到。

支持目标 macOS 13+；本版本界面只在 macOS 26、Apple Silicon 实机验证，不含 Intel 版本。

三类附件与已有安装

macOS-arm64.zip 是首次安装包；update.zip 供 2.6+ 客户端校验同 Release 的 Ed25519 清单与签名后使用，不要手动覆盖程序；source.zip 供开发和自行构建。

安装助手检测到 /Applications/Bark.app 或 ~/Library/Application Support/CodexBark 已存在会停止，不覆盖设备配置、规则或备份。2.4.x/2.5.x 没有新更新入口，请按可信维护指引保留数据启用 2.6，不删除数据强行重装。2.6 起可在设置中检查更新和选择自动下载，默认关闭、每 12 小时按需检查，安装仍需点击「重启并更新」。保留设备、既有 Hook/Skill 入口和授权策略。

发布者 Ed25519 更新签名不等于 Apple 公证。不要移除隔离标记或关闭 Gatekeeper。本工具只推送已接入事件，不是任意 App 全通知转发器。

接入其他 Codex 目录

没有找到 CLI，或使用多个独立 CODEX_HOME 时，先安装 App，再按 完整接入指南操作。已有接入目录换账号无需重新填写手机地址。

安装失败与卸载

如果安装中途停止，共用运行目录和配置备份会保留。请先核对安装指南中的恢复步骤，不要反复运行安装，也不要删除正在使用的目录。在 App「设置 → 高级 → 卸载」移除通知入口；保留备份目录供检查。
