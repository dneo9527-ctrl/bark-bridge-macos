# 隐私与数据流

设备地址包含手机推送密钥。只在本机设置面板隐藏输入框输入，使用受限本地文件保存。发送时通过子进程 stdin 提交 HTTPS 请求，不出现在进程命令参数。设备密钥不写入事件日志或 SQLite 去重状态。

App 不读取账号令牌，也不打开会话 transcript 文件。Hook 输入的 transcript 路径只用于解析符合格式的文件名 UUID。聊天名称来自 CODEX_HOME 的只读名称元数据，名称索引读取有大小及时间限制；查询不包含 first_user_message 等正文列。现有数据库结构是兼容性依赖，不是永远稳定的接口。

内容预览开启时，选定的 Bark 服务会收到聊天名、有限长度的问题与选项或固定完成/授权文案。权限提醒不发送授权命令，完成提醒不发送回复正文。常见密钥形式会脱敏，不能保证识别所有敏感内容；不希望外发摘要时关闭“手机内容预览”。

备份可能包含用户原 Codex 配置或原 Hook 定义，仅供本机回滚，不能作为公开发布素材。仓库不应包含真实手机配置、账户资料、SQLite、事件日志、聊天截图或安装备份。测试使用临时假设备密钥及 localhost TLS。

自检和诊断只报告固定类别及安全元数据。服务器已接收仅证明网关接受，不能证明 APNs 或手机最终展示。

2.6.1 起，仅 Codex 来源显式设置 `isArchive=1`，请求手机 Bark 保存收到的消息。开启预览时聊天名及有限问题摘要也可能保存在手机历史；关闭预览时只保存实际发送的通用文案。用户可在手机 Bark 中管理、删除记录。本工具不指定额外的历史到期时间；过去未保存的通知无法补回。Mac 脱敏发送日志与手机消息历史是独立记录。其他来源及旧调用仍沿用原来的归档策略。

Codex 通知附带 Codex 自身图标的固定公开 URL，图片托管在本项目 GitHub 的 `raw.githubusercontent.com`，固定到不可变提交，不含设备密钥、聊天信息或本机路径。Bark 手机客户端可能联网获取图片；Mac 发送器不额外下载或检查图片。关闭内容预览仍附带静态来源图标。Codex 图稿归 OpenAI，见[第三方图稿说明](THIRD_PARTY_ARTWORK.md)。
